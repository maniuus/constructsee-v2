API AHSP 2026 — struktur data analisa harga satuan

Database yang Anda telusuri di katalog dan yang dipakai aplikasi ConstrucSee disusun sebagai API terstruktur. Halaman ini mendokumentasikan struktur datanya — relasi antarberkas, skema, dan contoh isinya. Datanya dibangun dari dokumen resmi SE DJBK No. 47/SE/Dk/2026 Lampiran VI bidang Cipta Karya sebagai satu-satunya sumber. Berkas data utuhnya tidak diterbitkan untuk diunduh — silakan telusuri seluruh isinya secara interaktif di katalog.

Berkas penyusun database

Database tersusun dari berkas-berkas JSON berikut. Nama berkas di bawah ini adalah nama dataset di dalam sistem ConstrucSee — bukan tautan unduhan.

    {"grup": "Tenaga Kerja", "komponenId": "TK001", "namaTabel": "Pekerja",

Cara data saling terhubung

  • Pekerjaan dikenali dari kode-nya (mis. 5.4.1.18) — kode adalah kunci utama dan tidak berubah antarversi.
  • Analisa memuat satu objek per kode pekerjaan; setiap baris merujuk komponen lewat komponenId.
  • Komponen dikenali dari id-nya: TK… di tenaga.json, BH… di bahan.json, AL… di peralatan.json, LN… di lainnya.json.
  • Koefisien berarti kebutuhan komponen per 1 satuan pekerjaan (mis. 0,6 OH Pekerja per 1 m' pagar).
  • Data ini tidak memuat harga — AHSP resmi memang hanya memuat koefisien; harga dasar diisi saat menyusun RAB sesuai daerah proyek.

Ketentuan

Data dasar AHSP adalah dokumen publik pemerintah (SE DJBK Kementerian PUPR). Susunan database ini adalah bagian dari produk ConstrucSee: isinya dapat ditelusuri bebas di katalog, sedangkan berkas data utuhnya tidak dibagikan untuk diunduh. Periksa kembali angka penting ke dokumen resmi sebelum dipakai pada penawaran atau kontrak.
